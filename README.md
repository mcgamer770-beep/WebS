# Leonardo Ramia - Architecture Portfolio

Complete static website, including the latest vector arrow update. No npm install, build step, API keys or paid dependencies are required.

## Add to GitHub

1. Extract this ZIP on your computer.
2. Create a GitHub repository.
3. Upload the contents of this folder, with `index.html` at the top level. Do not upload only the ZIP.
4. Commit your files.

## Hosting

This is a plain HTML, CSS and JavaScript website, ready for static hosting such as GitHub Pages. Configure your host to serve the repository root. Relative links support both a root domain and a repository subdirectory. Publishing makes the included portfolio and CV accessible to visitors.

## Preview locally

With Python installed, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Open http://localhost:8000 in your browser. On Windows, `py -m http.server 8000` also works when the Python launcher is installed.

## Edit the website

- `index.html`: homepage, About, contact and project previews.
- `utility-bridge/index.html`: Studio 3 project.
- `construction-reform/index.html`: Studio 4 project.
- `river-ecosystems/index.html`: landscape project.
- `elemental-pavilion/index.html`: construction project.
- `style.css`: layout, typography, colours, responsive styling and animations.
- `app.js`: drawing viewer, zoom, reveals and chapter navigation.
- `assets/`: project images and the CV PDF.

Keep images and their filenames together with the HTML. Directional arrows are inline SVG icons, so they will not change to emoji on phones. This export preserves the current layout and content; only local link paths have been adapted for portable hosting.

## Included content

The images and CV are included. Existing collaborative project credits remain in place. No credentials, source-control history or private hosting configuration are included. This archive is an export; future edits here do not automatically synchronise with the original hosted Site.
